# BUILD: CODE ZERO
## AI-Powered GitHub Regression Investigation & Code Infection Analysis Platform

You are an elite full-stack TypeScript engineer, AI systems architect, and award-winning product designer.

Build a complete, production-quality, visually exceptional web application called **CODE ZERO**.

**Tagline:** "Find Patient Zero in Your Codebase."

### THE VISION

CODE ZERO is an AI-powered GitHub repository investigation platform that treats software regressions like infections spreading through a biological system.

Every repository is a patient. Every commit is a potential mutation. Every regression is an infection. Every affected function is part of the infection's potential spread.

The platform allows developers to import GitHub repositories, travel through commit history, investigate suspicious changes, visualize dependency propagation, identify potential regression origins, compare working and broken versions, receive Gemma 4-powered explanations, generate fixes, and export investigation reports.

The result should feel like an advanced biomedical research laboratory combined with a sophisticated developer intelligence platform.

This is NOT a generic chatbot, basic GitHub dashboard, or static concept website.

Build a functional, interconnected application with real data, meaningful analysis, and an extraordinary user experience.

### Frontend

### Architecture
Use a monorepo:

```text
code-zero/
├── apps/
│   ├── web/

├── packages/
│   ├── shared/

├── .env.example
└── package.json
```

Use shared TypeScript types and schemas.

Never expose GitHub tokens or AI service credentials to the browser.

All GitHub API calls, model inference, and repository processing must happen through the backend.
